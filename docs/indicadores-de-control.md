# Indicadores de Control

Estos indicadores sirven para saber si el módulo de sincronización funciona bien una vez implementado. Cada uno tiene un valor esperado y un responsable que lo revisa.

| Indicador | Qué controla | Valor esperado | Responsable |
|---|---|---|---|
| Tiempo de sincronización | Que el stock se actualice rápido entre Moebius y Tiendanube | Menos de 1 minuto | Área de Sistemas |
| Sincronizaciones con error | Que el sistema no falle seguido | Casi ninguna | Área de Sistemas |
| Ventas online sin stock | Que no se venda online algo que no está en el depósito | Ninguna en los primeros 90 días | Área de Marketing |
| Armazones sincronizados | Que estén cargados todos los armazones más vendidos | El 100 % en la primera etapa | Área de Sistemas |
| Armazones no encontrados | Que la ubicación cargada en el depósito sea la correcta | Menos de 1 por mes | Sector de Armazones |

## ¿Qué pasa si no se cumple?

- Si la sincronización es lenta o falla seguido, Sistemas revisa los errores junto con el equipo de Moebius.
- Si hay ventas online sin stock, se revisa cada caso para ver si fue un error del sistema o del conteo físico.
- Si no están todos los armazones más vendidos, no se pasa a la siguiente etapa.
- Si aparecen armazones que no están donde dice el sistema, se hace un conteo del depósito.

Varios de estos indicadores salen de las metas de la Entrega 2, y los datos para medirlos se toman del registro de sincronizaciones definido en la Entrega 3.
